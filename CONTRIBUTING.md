# Contributing

Thanks for helping. Good first issues:
1. Add unit and statement conventions for another country (`skills/finsight-quant-analyst/references/`).
2. Add a ratio or forensic screen to `src/finsight/forensics.py` with a hand-computed test.
3. Add a chart type to `src/finsight/charts.py` with a synthetic test case.

Rules: tests must pass (`python -m pytest -q`), math changes need tests, no fabricated benchmark numbers, no secrets or copyrighted filings in commits. Output is analysis tooling, not investment advice.
